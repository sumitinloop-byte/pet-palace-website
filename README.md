A dynamic, conversion-focused business website built for **Pet Palace**, a local pet shop in Bhubaneswar, Odisha[cite: 1, 2]. Designed mobile-first to ensure seamless navigation, instant touch actions, and fast lead generation on smartphones[cite: 2, 3].

## 🎯 Overview & Business Context

Pet Palace provides pet supplies and services for dogs, cats, birds, rabbits, and other pets[cite: 1, 2]. Despite having a strong physical footprint and a 3.9-star Google rating with 988 reviews[cite: 1, 2], the shop lacked an official website or direct digital channel[cite: 1, 2].

This project creates a modern digital web presence aimed at converting local directory searchers into direct phone calls and WhatsApp leads[cite: 2, 3].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS / Tailwind CSS[cite: 3]
- **Icons & Fonts:** FontAwesome 6, Google Fonts
- **Scripting & Logic:** Vanilla JavaScript (ES6+) for drawer toggles, gallery modals, and form query handling[cite: 3]
- **Deployment:** Vercel / Netlify continuous delivery[cite: 1]

---

## 📱 Key Features & Mobile Optimizations

1. **Mobile Sticky Contact Bar:** Fixed bottom bar on mobile screens with direct triggers for Call (+91 93376 27738), WhatsApp Enquiry, and Google Maps Directions[cite: 2, 3].
2. **Direct WhatsApp Lead Routing:** Product cards and query forms pass pre-filled messages directly to WhatsApp without requiring a complex backend[cite: 3].
3. **Interactive Photo Lightbox:** Tap-to-expand gallery view for viewing pet imagery and supplies[cite: 3].
4. **Google Business Proof:** Prominently presents verified business rating (3.9★) and review count (988)[cite: 1, 2].
5. **Responsive Layout:** Adaptive design scaling seamlessly from mobile viewports up to desktop displays[cite: 2, 3].
